# 🏏 IPL 2026 Ticket Booking Website

## About the Project
This project is a responsive IPL Ticket Booking Website developed using HTML as part of Activity 1.

## Features
- Navigation bar with Matches, Book Ticket, My Bookings and Guidelines.
- IPL 2026 banner section.
- About IPL section with popular teams and venues.
- Match schedule displayed in a table.
- Team filter dropdown.
- Ticket booking form.
- Booking summary card.
- My Ticket Bookings section.
- Ticket booking guidelines.

## Technologies Used
- HTML5
- Visual Studio Code
- Live Server

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click and select Open with Live Server.

## Project Structure
- `index.html` – Main webpage.
- `README.md` – Project documentation.
